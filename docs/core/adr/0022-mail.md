# ADR 0022: Mail

- Status: accepted (0.3, M19)
- Date: 2026-10-24

## Context

0.3 needs mail (welcome mails, password resets, invitations) without
weakening the invariants: nothing secret in logs, queue payloads, audit or
responses; settings edited in the panel (ADR 0015); work queued with the
change that causes it (ADR 0016). An SMTP server set in the panel is also a
way to make the application connect somewhere and hand over a password.

## Decision

- **Module** `rustcms_core::mail` (feature `mail`, default in `rustcms`):
  drivers `disabled` (default), `smtp` (lettre 0.11.23, rustls, no pool),
  `log` (counts and message id; the body only with `log_body`, refused
  outside `APP_ENV=local`), `memory` (tests).
- **Server**: `source = "settings"` reads the `mail` group (`MailSettings`) at
  each send, so a change on any instance applies at once; `source = "config"`
  reads `[mail.smtp]`.
- **Trust boundary**: `settings.mail.update` is the power to use the saved
  credentials and open outbound connections. The operator bounds it with
  `allowed_hosts` / `allowed_ports` / `allow_insecure` in the configuration
  (`allowed_hosts` required in production with `source = "settings"`);
  one check (`MailPolicy::check`) runs at config load, page save and every
  send. A secret field may be bound to others (`SettingField::kept_while`):
  the password is cleared when host, port or user name change without it.
- **TLS**: `starttls` is required STARTTLS (`Tls::Required`), `tls` is
  implicit TLS; certificates and names verified (webpki roots, plus
  `tls_ca_file`); `none` only with `allow_insecure` and without
  authentication. One timeout bounds a whole send.
- **Errors** are codes (`MailError`); lettre errors are classified (timeout,
  TLS, 530/534/535/538 auth, permanent, transient, connect) and only the code
  and status number are logged. Mail jobs return `queue::Failure`s, so the
  queue logs the code, never an error chain. Permanent codes use
  `Failure::permanent()` (new: `queue::Permanent`, failed at once — ADR 0016
  amended); `last_error` is `code: message` with a fixed message.
- **Outbox**: `send_later(txn, MailJob)` dispatches `mail.send` (8 runs);
  `Message-ID` `{job}.{run}@{host}`; delivery at least once. `data` must hold
  no secret: mails with secrets are sent by jobs of their own.
- **Templates**: per language `{name}.subject.txt|.txt|.html`, embedded by
  `mail_template!`, re-read in local development; the shared bounded
  minijinja environment (`rustcms_core::template`, also used by the panel's
  custom pages): text not escaped, HTML always, no way to mark safe, no
  includes; data 64 KiB, output 256 KiB per part; subjects one line
  (a line break fails the mail).
- **Rate**: `max_per_minute` per process (web and worker processes each).
- **Panel**: `AdminProvider::mail_settings()`; `POST settings/mail/test`
  (admitted with `settings.mail.update` before the body; 5/min/user; saved
  settings only; `{ok, code}`; audit `mail.test_sent` with the recipient
  masked).

## Consequences

- An operator who trusts mail admins writes `allowed_hosts = ["*"]`.
- A mail may be repeated after a cut run; recipients may see two copies.
- Limits are per process, not shared (several instances multiply them).
