# Báo cáo M20: Quên mật khẩu, mời user, ghi nhớ đăng nhập

> Ngày: 25/10/2026. Plan: `~/.claude/plans/rustcms-0.3-m19-m23.md` (v1 + v2).

## Đã làm
- Bảng `user_tokens` (HMAC của secret, một token mỗi user + mục đích), cột lời mời trên `users`.
- Quên mật khẩu: luôn 202 `{}` cho mọi email, một lần insert job; job phát token dưới khoá user và gửi mail ngay
  (token không nằm trong queue); request id/thời điểm chống request cũ đè request mới; cooldown cho request khác;
  hạn 15 phút cho request.
- Link để secret trong fragment; trang reset/invitation có `Referrer-Policy: no-referrer`; SPA fetch đặt
  `referrerPolicy: same-origin` (không nới kiểm Origin).
- Dùng token: kiểm password trước, budget theo token chỉ sau khi secret khớp, khoá user → token, kiểm lại toàn bộ,
  password + xoá token + thu hồi phiên/token trong một transaction; một lỗi 422 duy nhất cho token.
- Mời user: `users.invite`, `RbacService::invite_user` / `resend_invitation`, route admin, SPA (ô "gửi lời mời",
  badge "Đang mời", nút gửi lại). User đang chờ không đăng nhập được, không được đếm là super admin cuối cùng;
  admin đặt mật khẩu → kết thúc lời mời.
- Ghi nhớ đăng nhập: `[auth] remember_days` (30), cookie `Max-Age`, phiên sống lâu hơn; vẫn bị thu hồi ngay.
- `Passwords::verify` coi hash không hợp lệ như user không tồn tại (cùng thời gian).
- Test: 21 test 3 DB (auth), oracle auth (7 case) và admin (4 case), Vitest 4.
