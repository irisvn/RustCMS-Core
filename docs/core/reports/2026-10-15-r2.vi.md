# Báo cáo R2: tầng API cho ứng dụng

> Ngày: 15/10/2026 · trên `acb025a` (R1) · chưa commit.
> Plan v2 đã chỉnh theo review của Codex (2 P1, 6 P2, 1 P3).

## 1. Vấn đề
`examples/demo/src/api.rs` gom 5 việc vào một file:
- khai báo route;
- handler;
- validate input;
- định dạng JSON trả về;
- đọc `?page=`.

Lý do: framework chưa có quy ước cho code HTTP của app, và app phải tự viết nhiều thứ:
- khai báo route hai lần (`routes` và `describe_routes`), dễ lệch nhau;
- tự parse tham số phân trang;
- tự parse và validate body.

## 2. Đã làm

### Framework
- **`ApiRoutes` + `Access`** (`rustcms::prelude`):
  - mỗi route bắt buộc khai báo quyền: `Access::public()`, `authenticated()` hoặc
    `can("posts.create")`;
  - quyền được kiểm **trước khi handler chạy**, nên trước mọi extractor: thiếu
    quyền thì luôn là 403, dù body, path hay query sai thế nào. Test chứng minh body
    **không hề bị đọc**;
  - chỉ chấp nhận token của API guard; session của admin bị 401;
  - route nằm dưới `auth.admin_path` bị từ chối khi đăng ký;
  - một lần khai báo vừa gắn route, vừa có trong `route:list`;
  - `nest`, gộp nhiều method trên cùng path, `HEAD` theo quyền của `GET`, method
    không khai báo trả 405;
  - `AuthProvider::api_permissions(&routes)` tự khai báo permission cho API guard.
    Group lấy theo tiền tố của tên; group mà app khai báo tường minh được giữ nguyên.
- **`Throttle<N>`:** giới hạn số request mỗi phút theo user và route, chạy trước khi
  đọc body; quá giới hạn thì 429 kèm `Retry-After`.
- **`Pagination`:**
  - đọc `?page` (1–10.000) và `?per_page` (1–100), có decode URL;
  - giá trị ngoài khoảng, không phải số, hoặc truyền hai lần → 422 trên đúng field đó.
- **`ApiPage<T>`:** trả về `{data, meta: {page, perPage, total, lastPage}}`.
- **`Validated<T>` + `Validate`:**
  - lỗi body: 413 quá lớn, 400 không phải JSON, 422 sai cấu trúc;
  - sau đó gọi `validate`, hàm này có thể chuẩn hoá dữ liệu (ví dụ trim) và trả lỗi
    theo field.

### App và generator
- Quy ước app mới: `src/http/api/<table>/` gồm:

  | File | Vai trò | Tương đương Laravel |
  |---|---|---|
  | `mod.rs` | khai báo route | `routes/api.php` |
  | `handlers.rs` | xử lý request | controller |
  | `requests.rs` | input + validate | FormRequest |
  | `json.rs` | định dạng dữ liệu trả về | API Resource |

- Template `rustcms new` có sẵn `src/http/api/` (route `ping` chuyển vào đây).
  `app.rs` dùng `api_permissions` và `register`.
- **`rustcms make:api <Model>`:**
  - sinh `list` (có phân trang, sắp xếp mới nhất trước) và `show`;
  - `json.rs` sinh từ các cột của model, theo wire format: số 64-bit, decimal,
    UUID và thời gian thành chuỗi; cột nhạy cảm và kiểu chưa hỗ trợ bị bỏ qua;
  - từ chối model có khoá chính nhiều cột;
  - kiểm mọi anchor trước khi ghi bất kỳ file nào; không bao giờ ghi đè.
- **Demo:** `src/api.rs` → `src/http/api/posts/{mod, handlers, requests, json}.rs`.
