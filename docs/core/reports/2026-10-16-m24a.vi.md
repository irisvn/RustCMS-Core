# M24a: phân phối binary và docs (2026-10-16)

## Đã làm
- Repo `irisvn/RustCMS-Core` (source, public) và `irisvn/RustCMS` (Releases, `install.sh`, Pages): ADR 0025.
- `rustcms new` sinh dependency `git + tag` của RustCMS-Core; `cargo generate-lockfile`; CI cho app.
- `release.yml`:
  - verify version, kiểm `DIST_TOKEN`, chờ CI của commit trên `main` (không chạy lại);
  - mỗi target: build → đóng gói → cài bằng `install.sh` → app mới từ tag → build và test;
  - Release draft → kiểm checksum → publish; Pages.
- Spike: cả 5 target đều build được và app sinh ra pass test (Linux musl là binary tĩnh, macOS minos 11.0).
- Theo quyết định của anh:
  - **bỏ Windows** (WSL dùng bản Linux);
  - **tạm tắt job `test-rust` trong CI** (chạy `just test-matrix` ở local trước khi release).
- `.gitattributes` ép LF: trên Windows, template nhúng bị CRLF làm hỏng các generator.

## Test flaky cần xử lý (lý do tạm tắt `test-rust`)
- `rustcms-admin::http_api blocked_session_renewal_does_not_hide_a_committed_write::mysql`: timeout 300 giây trên runner CI (run Release v0.3.1-rc.1).
- `rustcms-admin::media deleted_media_files_are_removed_and_abandoned_uploads_cleaned::sqlite`: fail một lần trên CI của `main` (commit ba90580).
- Cả hai đều pass ở local (1310/1310) và ở các run CI trước đó. Cần chạy lặp lại trên Linux để tìm nguyên nhân rồi mới bật lại `test-rust`.
