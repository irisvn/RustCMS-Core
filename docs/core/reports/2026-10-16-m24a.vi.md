# M24a: phân phối binary và docs (2026-10-16)

## Đã làm
- Repo `irisvn/RustCMS-Core` (source, public) và `irisvn/RustCMS` (Releases, `install.sh`, Pages): ADR 0025.
- `rustcms new` sinh dependency `git + tag` của RustCMS-Core; `cargo generate-lockfile`; CI cho app.
- `release.yml`:
  - verify version, kiểm `DIST_TOKEN`, chờ CI của commit trên `main` (không chạy lại);
  - mỗi target: build → đóng gói → cài bằng `install.sh` → app mới từ tag → build và test;
  - Release draft → kiểm checksum → publish; Pages.
- Spike: cả 5 target đều build được và app sinh ra pass test (Linux musl là binary tĩnh, macOS minos 11.0).
- Theo quyết định của anh:
  - **bỏ Windows** (WSL dùng bản Linux) và **bỏ macOS Intel** (runner chạy 18 phút; ai cần thì tự build bằng `cargo install --git`);
  - **tạm tắt job `test-rust` trong CI** (chạy `just test-matrix` ở local trước khi release).
- `.gitattributes` ép LF: trên Windows, template nhúng bị CRLF làm hỏng các generator.

- `rustcms-admin::http_api blocked_session_renewal_does_not_hide_a_committed_write::mysql`: timeout 300 giây trên runner CI (run Release v0.3.1-rc.1).
- `rustcms-admin::media deleted_media_files_are_removed_and_abandoned_uploads_cleaned::sqlite`: fail một lần trên CI của `main` (commit ba90580).
- Cả hai đều pass ở local (1310/1310) và ở các run CI trước đó. Cần chạy lặp lại trên Linux để tìm nguyên nhân rồi mới bật lại `test-rust`.

# M24b: các lệnh doctor, upgrade, self-update, docs

## Đã làm
- **`rustcms doctor`** kiểm từng mục, kèm hướng dẫn sửa:
  - Rust và Cargo ≥ MSRV (đọc từ `rust-version`);
  - trình biên dịch C: biên dịch thử thật một file nhỏ;
  - git, tag Core qua `git ls-remote --exit-code` (exit 2 = không có tag → FAIL; lỗi mạng → WARN);
  - curl;
  - bản mới nhất (offline → WARN);
  - version của app.
- **`rustcms upgrade`**:
  - chỉ lên đúng version của CLI (CLI biết pin SeaORM của chính nó);
  - dùng `toml_edit`, giữ comment và features; có `--dry-run`; lỗi `cargo update` → khôi phục cả `Cargo.toml` và `Cargo.lock`;
  - từ chối `path`, workspace, dependency bị đổi tên, repo khác, và hạ version (trừ `--force`);
  - chuyển được app cũ đang dùng `rustcms = "0.3.0"` sang git + tag.
- **`rustcms self-update`**:
  - chỉ chạy khi có `install.json`; có lock `update.lock` (lock quá 10 phút coi là lock cũ, bị bỏ);
  - các bước: tải → checksum → chỉ lấy file `rustcms` → chạy thử `--version` → `rename` atomic trong `bin/`.
- **`rustcms docs`**:
  - bản release nhúng docs (`build.rs`: `RUSTCMS_DOCS_DIR`; có `RUSTCMS_RELEASE` mà thiếu docs thì fail);
  - giải nén atomic vào thư mục cache, có marker `.complete`; bản build thường thì mở `/v/X.Y.Z/` online.
  - `--version` in kèm target.
- Release workflow: build với docs nhúng; smoke chạy `--version` (đúng version và target), `doctor`, `docs --print-path`.

## Test
- Unit: 46 test (tag, checksum, doctor, upgrade gồm cả khôi phục khi `cargo update` offline lỗi, docs, lock).
- Integration `tests/self_update.rs` (mirror `file://`, không cần mạng): update thành công; checksum sai giữ bản cũ; không có `install.json` thì từ chối.
- Chạy tay trên máy anh: `doctor` OK đủ 8 mục; `upgrade --dry-run` từ v0.3.0; build có docs nhúng, `docs --print-path` ra đúng đường dẫn.
- Chưa chạy: `test-matrix` (không đổi framework); E2E chạy trên CI.

## Codex verify M24b: không có P1; đã sửa 11 điểm P2 và 3 điểm P3
- **self-update:**
  - lock giữ bằng OS (`File::try_lock`, tự nhả khi tiến trình thoát; không còn lock "quá hạn" bị cướp);
  - mọi quyết định đưa ra sau khi giữ lock, từ version của binary đang có trên đĩa;
  - `install.json` được đọc, kiểm và chuẩn bị trước khi thay binary;
  - version và target của binary tải về phải khớp chính xác (trước đây `0.4.10` được chấp nhận cho `v0.4.1`).
- **upgrade:**
  - chỉ `NotFound` mới tính là chưa có lockfile (lỗi đọc khác thì dừng, không xoá lock khi khôi phục);
  - luôn kiểm và dựng đủ mọi chỉnh sửa, nên app đã ở tag mới nhưng mới nâng một nửa vẫn được nâng nốt;
  - giữ comment trên cùng dòng khi thay giá trị.
- **doctor:**
  - mỗi lệnh con có thời hạn;
  - git không hỏi credential (tắt helper, askpass và prompt);
  - kết quả in ngay sau từng mục; mục bản mới nhất chỉ chờ tối đa 10 giây;
  - trên macOS chạy `xcode-select -p` trước, không gọi shim `cc`/`git` khi chưa có Command Line Tools;
  - kiểm version của cargo.
- **docs:** giải nén tuần tự qua lock, bên ghi xong trước thắng, không bao giờ xoá bản docs đã hoàn chỉnh; có test 8 luồng chạy đồng thời.
- **Tên lệnh:**
  - `make:command` từ chối tên trùng lệnh của `rustcms`;
  - `rustcms -- <cmd>` luôn chuyển tới app (đã ghi vào docs).
- **CI:** job `cli` chạy toàn bộ test của CLI.
- **Docs:** `cli.md` đã có `self-update --version` (bộ lọc dựa theo action của clap, không theo id của argument).
