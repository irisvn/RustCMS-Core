# Báo cáo M15d: trang Queue trong Admin

> Ngày: 21/10/2026 · trên `24c3145` · plan `rustcms-0.3-m15d.md` v2 (Codex review plan: 3 P1, 4 P2, 2 P3).

## Thay đổi
- Core `rustcms::queue::manage`: `JobStatus` (pending, scheduled, running, stalled, failed) tính theo đúng điều kiện
  của worker (cutoff `now - clock_skew_secs`; stalled = lần thử cuối hết lease, chờ reap); `Clock`; `counts`;
  `retry` / `forget` / `cancel` là một câu lệnh có điều kiện (cancel dùng đúng điều kiện claim). `queue:retry` xoá luôn
  reservation cũ.
- Admin `features/queue.rs`: `GET queue` (đếm theo queue/trạng thái, cấu hình worker, `canManage`), `GET queue/jobs`
  (lọc status/queue/kind, keyset `(created_at, id)` với cursor instant chính xác), `POST queue/jobs/{id}/{retry,
  forget,cancel}`. Quyền `queue.view`, `queue.manage` (thao tác cần cả hai, kiểm trước khi parse id và kiểm lại dưới
  khoá RBAC bằng `begin_as`). Audit `queue.retried/forgotten/cancelled` trong cùng transaction. Không trả payload,
  `reserved_by`. Slug `job`, `queue` dành riêng; `SystemLinks.queue`.
- Bỏ thao tác hàng loạt khỏi panel (theo Codex: khó replay an toàn); CLI vẫn có `--all`.
- SPA: trang System → Queue (thẻ đếm bấm để lọc, bộ lọc, bảng job, hành động có hộp xác nhận, thông báo lỗi 409 có
  bản dịch), icon `layers`, i18n en/vi.
- Docs: guide `queues.md` (mục "The Queue page"), admin-api, error-codes, overview, production, release notes,
  upgrade; core admin-protocol, ADR 0016 (mục Admin page), architecture, CHANGELOG, roadmap.
