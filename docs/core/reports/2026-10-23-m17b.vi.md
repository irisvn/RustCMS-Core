# Báo cáo M17b: Import CSV (+ sửa M17a theo Codex verify)

> Ngày: 23/10/2026 · trên `9ea0531`. Plan `~/.claude/plans/rustcms-0.3-m17.md` (v2). ADR 0021.

## Import
- Khai báo: `ResourceMeta::importable()` / `import_key(field)`. Field làm key phải có một constraint
  `ResourceMeta::unique` riêng cho cột đó (kiểm lúc boot). Thêm ability `import`.
- **Upload**:
  - `POST {slug}/imports`, body là file CSV.
  - Kiểm quyền trước khi đọc body; body limit riêng cho từng resource import được (5 MiB).
  - Parse bằng crate `csv` 1.3.1: UTF-8, bỏ BOM, ≤ 10 000 dòng, ≤ 100 cột, ô ≤ 10 000 ký tự, header không trùng.
  - Tối đa 3 import đang chờ mỗi user, đếm dưới khoá theo user.
  - Ghi row `imports` trước, rồi mới ghi file vào storage. File tạm tự xoá cả khi request bị huỷ.
- **Preview** `POST imports/{id}/preview`: kiểm tĩnh từng dòng (`accept_input` của create/update), không hook, không ghi
  DB. Dòng có key thì kiểm như update.
- **Run** `POST imports/{id}/run`: chỉ một lần (update có điều kiện `uploaded → running` + dispatch trong cùng
  transaction); lần sau trả 409 `import_started`.
- **Job** `admin.import`:
  - Mỗi lô 100 dòng tải lại user (active, `auth_version`, `import`).
  - Mỗi dòng ghi qua `create`/`update` với idempotency key `import-{id}-{row}`, nên chạy lại không ghi trùng
    (`update` được thêm claim cho việc này).
  - Có key: 0 bản ghi khớp → tạo, 1 → cập nhật (không ghi lại cột key), nhiều hơn → lỗi `several_matches`.
  - Lưu tiến độ sau mỗi lô. Xong: chuyển `done` và ghi audit `imported` trong cùng transaction.
- **Báo cáo**: dòng, field, message kèm code/params để SPA dịch; không bao giờ chứa giá trị trong file.
- **SPA**: trang `/r/{slug}/import` gồm upload → ghép cột → Kiểm tra → Nhập → theo dõi tiến độ → báo cáo. Nút "Nhập
  CSV" trên trang danh sách. Thêm key i18n en/vi.
- **Ví dụ**: LMS learners (key email, staff có `learners.import`); demo tags (key name).

## Sửa M17a (Codex verify: 2 P1, 10 P2, 1 P3)
- **P1** Nhiều lần chạy job có thể trộn file và manifest → mỗi lần chạy ghi một object riêng (key suy từ id + attempt).
  Lần chạy xong đầu tiên publish file cùng danh sách key bằng một update có điều kiện; lần chạy thua tự xoá file của
  mình; prune xoá file của mọi lần chạy.
- **P1** Trường bị thu hồi quyền đọc giữa các lô vẫn bị xuất → kiểm lại cột ở mỗi lô.
- **P2**:
  - giới hạn byte: 10 MiB khi xuất ngay, 50 MiB khi chạy nền;
  - đếm số export đang chờ dưới khoá;
  - hỗ trợ `Idempotency-Key`;
  - body không rỗng bị từ chối (query lấy từ URL);
  - lần chạy cuối thất bại thì đánh dấu export `failed`; cutoff prune 6h;
  - file tạm có guard tự xoá, prune quét staging;
  - SPA kiểm lại phiên sau khi tải xong blob;
  - CSV: chặn ký tự điều khiển nằm sau khoảng trắng đầu; cột JSON ghi đúng JSON text.
- **P2** Test rút quyền theo từng lô: chưa có barrier để chèn thay đổi giữa hai lô; code kiểm lại cột ở mỗi lô, các
  test hiện có kiểm trước khi chạy và lúc tải.
- **P3** Lý do lỗi lưu dạng mã, SPA dịch en/vi.
