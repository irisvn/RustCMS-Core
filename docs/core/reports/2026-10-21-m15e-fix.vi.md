# Báo cáo M15e-fix: sửa theo Codex verify

> Ngày: 21/10/2026 · trên `68a5366`. Codex verify: 0 P1, 7 P2, 3 P3.

## Thay đổi
- **P2** Chặn `autoescape` bằng tìm chuỗi `{% autoescape` → `{%autoescape false%}`, tab/xuống dòng lọt qua. Giờ một
  lexer đọc phần code của template (bỏ qua comment và chuỗi) và lấy tên statement, nên khoảng trắng kiểu gì cũng bị
  chặn (`include`, `import`, `from`, `extends`, `autoescape`). Test thêm các biến thể khoảng trắng.
- **P2** Output được dựng xong toàn bộ rồi mới so với 512 KiB → render vào writer có giới hạn
  (`render_captured_to` + `Bounded`), dừng ngay khi chạm giới hạn. Test: vòng lặp 10 000 × 64 KiB, buffer ≤ 512 KiB.
  Docs nói rõ template là code của ứng dụng: giới hạn chặn output phình theo data, không biến template độc hại thành
  an toàn.
- **P2** Refetch trả 403/404 vẫn hiện data cũ của React Query → trang hiện lỗi, slot biến mất, script bị unmount.
- **P2** Callback của script không kiểm epoch → callback kiểm cả mount lẫn `api.epoch`, view mount lại khi epoch đổi,
  query key của page/slot có epoch.
- **P2** Script trả `undefined` vẫn được nhận → kiểm `{update, unmount}` như widget host; sai thì mark failed và xoá
  nội dung đã vẽ; cleanup luôn `replaceChildren`.
- **P2** Test "script chỉ nhận field đọc được" không kiểm được gì (editor không tạo/xem được post) → thêm resource
  `ledger` trong test (price khai báo nhưng cần `ledger.view_price`, `secret` không khai báo, scope theo tác giả). Seed
  thẳng hai bản ghi; kiểm có đúng một dòng "Mine", không có "Theirs", price, giá trị secret.
- **P2** `GET slots` trả 422 trước admission → tra resource (404), `admits(view)` (403), rồi mới trả lỗi tham số. Với
  policy mặc định, user không có `view` nhận 403 cho mọi biến thể tham số. Resource có policy riêng mà `admits` mặc
  định true thì giữ quy tắc của trang record (404/403 theo bản ghi).
- **P3** `make:page --script` sinh tên script mà panel từ chối lúc boot → kiểm mỗi phần 1–32 ký tự `a-z0-9-` trước
  khi ghi file.
- **P3** `lang:missing` bỏ sót `t( "x" )` và đọc sai chuỗi có escape → dùng lexer: chỉ tìm trong `{{ }}`/`{% %}`,
  cho phép khoảng trắng, xử lý `\"`, `\'`, `\\`, `\n`…; bỏ qua `data.t(…)`, `at(…)`, `t(name)`, chữ trong chuỗi và comment.
- **P3** Demo post stats đếm published trên 100 bản ghi đầu → đếm bằng `meta.total` của list có filter
  `published = true` (qua `ctx.records`, vẫn theo scope/policy).
