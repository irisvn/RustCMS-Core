# Báo cáo R3: cấu trúc app kiểu Laravel (phương án B) + khoá cha

> Ngày: 20/10/2026 · trên `d54a9dc` · plan `rustcms-0.3-r3.md` v2 (Codex review plan: 1 P1, 8 P2, 3 P3). ADR 0017, 0018.

## Thay đổi
- **Cấu trúc app** (ADR 0017): thư mục tên Laravel trong `src/` — `bootstrap/` (+ `providers.rs`), `providers/`
  (auth, admin panel, app service providers), `routes/api.rs`, `http/{controllers,requests,resources}`, `models/`,
  `services/`, `policies/`, `jobs/`, `settings/` (chỉ dữ liệu), `console/`, `admin/{resources,pages}`,
  `database/{migrations,seeders,factories}`, `tests/{support,feature}`.
- **Framework**: `rustcms::database::{Seeder, call, Factory}` (Factory chuyển từ testing, vẫn re-export;
  `try_create`), `AppBuilder::seeder`, `db:seed [--class] [--force]`, `migrate:fresh --seed`, `rustcms::clap`.
- **CLI**: template mới; `layout.rs` (đường dẫn, `ensure_module`, từ chối app cũ/lai); preflight mọi file + anchor
  trước khi ghi; `make:resource/api/migration/test` theo cây mới; mới `make:service/job/seeder/factory/settings/
  command`.
- **`lock_parent`** (ADR 0018): ghi bản ghi con khoá cha trước (cả cha cũ + mới khi chuyển), thứ tự
  idem → cha (cả lô, theo khoá) → con; hook/action chuyển sang cha chưa khoá → lỗi nội bộ + rollback; cha đổi giữa
  lúc đọc và lúc khoá → 409. Kiểm khi boot: field `belongs_to` đúng target, không tự trỏ, không chuỗi.
- Thông điệp unique constraint dịch theo request và có trong `lang:missing`.
- **Demo** chuyển cây mới (git mv, giữ tên migration — có test), `demo:seed` → seeders + `db:seed`, settings tách
  data/page. E2E dùng `db:seed`.

## Kiểm tra
- `parent_locks` 13/13 trên 3 DB; reverse check: bỏ khoá cha → race fail (PG/MySQL), test deadlock fail (PG/MySQL).
- `test-cli`: app mới + mọi `make:*` build, test pass, `cargo test --test feature -- --list` đủ module, `db:seed`,
  `--class`, lệnh sinh ra chạy được.
- Full gate: matrix SQLite + PostgreSQL + MySQL + Redis + S3 **1083/1083**, fmt, clippy (mặc định + redis,s3),
  `just features`, `just doc`, MSRV 1.94, E2E **36/36** (demo seed qua `db:seed`), `test-cli` xanh.
- Codex verify (0 P1, 9 P2, 2 P3): sửa trong commit tiếp theo (báo cáo `r3-fix`).
