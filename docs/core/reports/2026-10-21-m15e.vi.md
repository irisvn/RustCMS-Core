# Báo cáo M15e: tuỳ biến Admin

> Ngày: 21/10/2026 · trên `0ee3ab3` · plan `rustcms-0.3-m15e.md` v2 (Codex review plan: 3 P1, 7 P2, 2 P3). ADR 0019.

## Thay đổi
- **Theme**: token màu (light + dark), radius, font-family (trích dẫn), logo/favicon PNG/WebP/ICO (kiểm magic bytes),
  `ColorScheme`; mọi giá trị kiểm lúc boot, sinh stylesheet + ảnh có hash dưới `assets/ext/`; dark mode theo
  `data-scheme` (fallback theo hệ điều hành trước khi SPA chạy); token `--radius`, `--font-sans`; bộ class `rc-*`.
- **Trang & slot tuỳ biến**: `PanelPage`, `PanelSlot` (`Placement::RecordAside`), bắt buộc có quyền; template
  minijinja (luôn escape, không `safe`/`tojson`/`autoescape`/include, fuel, ≤ 512 KiB) rồi lọc bằng ammonia 4.2.0
  (allowlist theo thẻ, URL kiểm sau giải mã, không `id`/`name`/`style`/handler/form/frame/svg); hoặc script
  (`registerPage`/`registerSlot`). Ma trận quyền: không có trang nào → 403 mọi slug; slug lạ 404; slot thiếu quyền bị
  bỏ trước khi đọc data; slot đọc bản ghi như trang bản ghi.
- `Ctx::records` / `Ctx::record` đọc qua resource (scope, policy, field đọc được).
- **Cell tuỳ biến**: `TableColumn::cell` / `props`, `registerCell`; vocabulary 6.
- **SPA**: route `/p/$slug`, slot trên trang bản ghi, link nội bộ (`panelPath`, kiểm origin + ranh giới segment, không
  API/assets), vòng đời chung mount/update/unmount, lỗi được cô lập; logo, favicon, color scheme; `safeHref` từ chối `\`.
- **CLI**: `make:page [--script]`; `make:widget` ghi vào `resources/admin/js`; template có `resources/` và anchor
  `// rustcms:extensions`.
- **Ví dụ**: LMS (theme, Course overview, slot Seats, cell progress), demo (Post stats, slot Visibility; asset chuyển vào
  `resources/`).
- **Docs**: guide mới `admin/customizing.md`; cập nhật directory-structure, custom-fields, console, admin-api,
  release notes, upgrade, CLI reference, examples/lms; core ADR 0019, admin-protocol, architecture, CHANGELOG, roadmap,
  CLAUDE.md.

## Kiểm tra
- Unit: sanitizer (script/style/handler/frame/form/svg/math/template/noscript, id/name, link `//evil`, `/\evil`,
  traversal mã hoá, `javascript:` lẫn tab/khoảng trắng, `data:`), template (không tắt được escape, include/syntax
  → panic), theme (giá trị độc → panic).
- `custom` 5 test × 3 DB + 2 unit = 17/17; LMS 14 test × 3 DB = 42/42 (trang/slot theo scope instructor, theme, cell).
- Reverse check: bỏ sanitizer → test template fail.
- Vitest 190/190 (thêm 7); E2E 39/39 (thêm `custom.spec.ts`, không có CSP violation); `test-cli` (make:page template
  + script) xanh.
- Full gate: matrix SQLite + PostgreSQL + MySQL + Redis + S3 **1142/1142**, fmt, clippy (mặc định + redis,s3),
  `just features`, `just doc`, MSRV 1.94.
