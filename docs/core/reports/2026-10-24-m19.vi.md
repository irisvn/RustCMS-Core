# Báo cáo M19: Mail

> Ngày: 24/10/2026. Plan: `~/.claude/plans/rustcms-0.3-m19-m23.md` (v1 + v2 sau Codex review).

## Đã làm
- `rustcms_core::mail` (feature `mail`, mặc định trong `rustcms`): driver `disabled`/`smtp`/`log`/`memory`;
  server từ settings (đọc mỗi lần gửi) hoặc config; chính sách `allowed_hosts`/`allowed_ports`/`allow_insecure`
  kiểm ở boot, lưu settings, và mỗi lần gửi (bắt buộc `allowed_hosts` ở production khi `source = settings`).
- TLS: `starttls` = STARTTLS bắt buộc, `tls` = implicit; `none` chỉ khi `allow_insecure` và không AUTH.
  Một timeout cho cả lần gửi.
- Lỗi là code (`MailError`); log chỉ code + mã status SMTP; job mail trả `Failure` (log theo code).
  `Failure::permanent()` mới trong queue (ADR 0016 sửa đổi).
- `send_later` (outbox, job `mail.send`, 8 lần), `Message-ID` theo job + lần chạy.
- Template mail: `mail_template!` nhúng `.subject.txt/.txt/.html`, đọc lại khi local; môi trường minijinja
  dùng chung với trang tuỳ biến (đã chuyển sang `rustcms_core::template`); subject một dòng.
- Rate limit theo process.
- Admin: trang Mail (`mail_settings()`), `SettingField::kept_while` (đổi host/port/user mà không nhập lại
  password → password bị xoá), `validate_in`, `POST settings/mail/test` (admit trước body, 5/phút, audit che địa chỉ),
  SPA thẻ "Gửi thư thử".
- Test: memory driver (`TestApp::mails`), Mailpit trong docker compose + `RUSTCMS_TEST_SMTP` (gửi thật, STARTTLS bị
  từ chối khi server không có), oracle 3 case.
- Ví dụ: LMS gửi mail chào mừng (once theo ghế), demo driver log; cả hai có trang Mail.
- Hạ tầng: nextest dừng test sau 5 phút (một test treo dưới tải trước đây giữ cả lượt chạy).

## Chưa làm / để sau
