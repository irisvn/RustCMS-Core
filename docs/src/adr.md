# Decision records

Architecture decisions live in [`docs/adr/`](https://github.com/irisvn/rustcms/tree/main/docs/adr):

- 0001 — Generic CRUD over SeaORM via type-erased resources
- 0002 — Admin UI generated from a JSON schema rendered by a React SPA
- 0003 — Strict wire format for 64-bit integers, decimals and time
- 0004 — Two-level CLI: global generator, in-app console
- 0005 — Own session store, synchronizer CSRF, deterministic guards
